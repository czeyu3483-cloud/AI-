# Project Skills

本仓库给 Cursor Agent 用的技能包。实现功能前请先加载对应 skill。

| Skill | 用途 |
| --- | --- |
| `mock-interview-mvp` | 总边界、技术栈、开发顺序、验收 |
| `deepseek-llm` | DeepSeek API、env、schema、mock 降级 |
| `interviewer-fsm` | 压力面状态机、卡壳话术、红线 |
| `resume-pdf-report` | 简历解析与 PDF 报告 |

产品说明文档仍在 `/docs`；skill 是「编码时必须遵守的短手册」。
