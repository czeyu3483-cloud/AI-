# 仿真 AI 模拟面试官（本地 Demo）

研发岗模拟面试。浏览器可用，本地启动；DeepSeek 负责简历总结、话术润色与复盘。

## 功能

- 首页：岗位/风格/轨道选择（仅研发岗 + 压力面 + **业务面**可选；HR终面展示为「暂不可选」）
- 简历：粘贴/上传后点「开始面试」会在后台自动分析（**不展示 AI 预览**）
- 开场：口语化称呼 + 随机面试官名；当前 Demo 默认业务面
- 业务面题量：**自我介绍 + 约 4 主问题**（简历深挖×2 → 学科专业题 → 编程）；不问简历已写明的事实，围绕 WHY / 规模 / 职责 / 失败深挖；提问短前置「我看你的简历，我想问…」
- 一致性：每答对照简历字段 + 自我介绍 + 历史作答；冲突立刻打断澄清，记入 `inconsistencies`，终局按严重度汇总
- 编程题：编辑器手写提交；**面试中不宣判对错**，评价仅在终局复盘
- 过渡话术：禁止「我先记下了」；用「好的，那我们看下一个问题」等自然衔接；学科题当场不判对错
- 跑题：检测后纠偏拉回题目，不直接当完整作答推进
- 面试：真人感面试官画面（办公室虚化背景，人像静止无晃动）+ **点击麦克风**说话；说完再点一次提交
- 回复库：`src/lib/replyBank.ts` 目前仅 id 1–30（用户已确认）；`decideTurn` 优先关键词/正则命中，命中则**原样播报**（诚信类可直接结束面试）。31–100 待用户提供回复后再补，勿提前硬编码
- 复盘：结构化反馈（六维 强/中/弱/风险）+ PDF 下载；诚信失败不高分；空泛会标「回答不够细致」；学科题对照标准答案打分

## 合格面试官能力框架（`src/lib/interviewerPolicy.ts`）

集中口径，供 `decideTurn` / DeepSeek 润色 / 复盘共用：

| 能力 | 行为摘要 |
| --- | --- |
| 知道测什么 | 业务面偏 coding/设计/项目真实性/技术深度；HR终面偏沟通协作/学习潜力/文化适配/动机 |
| 追问核实 | 空泛最多 1 次短探，再软换题并打标 `vague_insufficient_detail` |
| 区分不会/没做过/编造 | 不会→分级提示；没做过→问相邻迁移；编造承认→诚信结束 |
| 帮组织表达 | 啰嗦/紧张时可教练「先说结论 / 拆成三点 / 聚焦负责部分」 |
| 分级提示 | L1 澄清 → L2 方向 → L3 具体 nudge（业务面更积极；HR 少技术向） |
  | 节奏 | 卡壳/空泛预算用尽即软换题；超长答「好的，那我们看下一个问题。」 |
  | 清晰打分 | 技术深度/分析/项目真实性/沟通/学习潜力/文化适配，轨道权重不同；学科题仅复盘对照标准答案 |
  | 校招 vs 社招 | 简历启发式推断；**无信号时默认校招/实习**（Demo 暂无独立 UI 开关） |
  | 专业语气 | 尖锐但不嘲讽；禁止羞辱词；禁止「我先记下了」记录腔 |

**未回归项**：点击麦克风、诚信结束、回复库 1–30、不评流畅度、人像不晃、全局挡薪资/录用八卦。

## 本地运行

```bash
cp .env.example .env.local
# 编辑 .env.local，填入 DEEPSEEK_API_KEY

npm install
npm run dev -- --port 3456 --hostname 127.0.0.1
```

打开 [http://127.0.0.1:3456](http://127.0.0.1:3456)

请用 **本机 Chrome** 打开，并允许麦克风。云端远程桌面里常听不到系统声、也收不到麦克风，这是环境限制，不是功能缺失。

## 环境变量

见 `.env.example`：

- `DEEPSEEK_API_KEY`（必填才能走真实 LLM；缺失时自动 mock）
- `DEEPSEEK_BASE_URL` 默认 `https://api.deepseek.com`
- `DEEPSEEK_MODEL` 默认 `deepseek-flash`
- `DEEPSEEK_THINKING=disabled`（建议关闭，否则简历总结可能拿不到正文）

**不要把 `.env.local` 提交到 git。**
